# Grex Parser

Grex Parser сам собирает данные о товарах с российских маркетплейсов и интернет-магазинов: название, артикул, цены и фотографии. Достаточно вставить ссылку на товар — программировать для этого не нужно, всё делается через веб-панель в браузере.

## Поддерживаемые маркетплейсы

| Маркетплейс | Домены |
|---|---|
| Wildberries | `wildberries.ru`, `.by`, `.kz` |
| Ozon | `ozon.ru`, `.by`, `.kz` |
| Яндекс Маркет | `market.yandex.ru`, `.by` |
| MegaMarket | `megamarket.ru` |
| ММ (бывший KazanExpress) | `mm.ru` |
| Ситилинк | `citilink.ru` |
| ВсеИнструменты.ру | `vseinstrumenti.ru` |
| CDEK.Shopping | `cdek.shopping` |
| Бигам | `bigam.ru` |

---

## Что умеет

- **Собирает карточки товаров** — название, артикул, цену (обычную и со скидкой), фотографии, описание и характеристики.
- **Следит за ценами** — периодически перепроверяет сохранённые товары и строит график изменения цены во времени.
- **Присылает уведомления** — при заметном изменении цены и по расписанию отправляет Excel-отчёт в Telegram.
- **Извлекает ссылки списком** — по ссылке на каталог или страницу продавца находит все ссылки на товары внутри.
- **Работает с большими списками** — можно загрузить файл со ссылками и обработать их все разом.
- **Отдаёт данные по API** — для тех, кто хочет подключить сбор товаров к своей программе или сайту.

## Быстрый старт

Понадобится компьютер с macOS или Linux (на Windows — через WSL или Git Bash) и установленный **Python 3.12+**. Если Python ещё не установлен, см. подробную инструкцию в [`docs/getting-started.md`](docs/getting-started.md).

1. Откройте терминал в папке проекта.
2. Запустите скрипт установки и старта:

   ```bash
   ./start.sh
   ```

   Скрипт сам создаст нужное окружение, установит все зависимости и браузер для парсинга Ozon/MegaMarket — вмешиваться не нужно, только дождаться окончания.

3. Когда в терминале появится строка `API: http://localhost:8004`, сервис готов к работе.
4. Откройте в браузере **http://localhost:8004/admin** — это и есть панель управления.

   Логин и пароль по умолчанию: **admin / admin**. Сразу после первого входа смените их в разделе «Настройки → Пользователи» — так безопаснее.

Остановить сервис — нажать `Ctrl+C` в том же терминале. Запустить снова — повторить `./start.sh`.

## Как пользоваться веб-панелью

Всё управление происходит в браузере на странице `http://localhost:8004/admin`. Разделы в левом меню:

| Раздел | Для чего |
|---|---|
| **Главная** | Коротко о продукте и ссылка на группу поддержки в Telegram. |
| **Цели** | Добавить ссылку на товар (одну или списком из файла) и запустить сбор данных. |
| **Извлечение ссылок** | Вставить ссылку на каталог или магазин продавца — получить список ссылок на все товары внутри. |
| **Товары** | Все собранные карточки товаров: поиск, фильтр по маркетплейсу, экспорт в файл. |
| **Мониторинг** | Включить слежение за ценой товара, посмотреть график её изменения или очистить мониторинг целиком. |
| **История задач** | Журнал всех запусков сбора данных — что удалось, что нет и почему. |
| **Поблагодарить автора** | Как поддержать проект: донат, звезда на GitHub, Telegram-группа. |
| **Настройки → Параметры мониторинга** | Подключить Telegram-бота для уведомлений о падении цены и регулярных отчётов. |
| **Настройки → Прокси** | Список прокси-серверов, если маркетплейсы блокируют прямые запросы. |
| **Настройки → Пользователи** | Управление логинами и паролями для входа в панель. |
| **Настройки → API-ключи** | Ключи доступа для REST API: создать, отозвать, посмотреть, когда ключ использовался. |

Типичный сценарий: зайдите в **«Цели»**, вставьте ссылку на товар, нажмите «Запустить» — результат появится в разделе **«Товары»**. Чтобы следить за ценой этого товара со временем, включите его в разделе **«Мониторинг»**.

## Настройка

Все параметры сервиса хранятся в файле `data/settings.yml` — обычному пользователю туда заходить не обязательно, значения по умолчанию уже работают. Файл пригодится, если нужно:

- сменить порт или адрес, на котором работает сервис (`app.host`, `app.port`);
- подключить прокси — добавить их в `data/proxy.txt` построчно в формате `login:password@host:port` и включить `proxy.active: true`;
- настроить Redis (`redis.host`, `redis.port`) — он не обязателен, но без него не скачиваются фотографии товаров.

Полное описание всех настроек — в [`docs/getting-started.md`](docs/getting-started.md).

---

## Возможные проблемы

| Проблема | Решение |
|---|---|
| Redis недоступен | Сервис всё равно запустится, но фотографии товаров не будут скачиваться. Запустить Redis на macOS: `brew services start redis` |
| Не находит браузер для Ozon/MegaMarket | Выполните `.venv/bin/patchright install chromium` |
| При первом парсинге Ozon/MegaMarket/Яндекс Маркета открывается окно браузера | Это нормально — так собираются куки; при следующих запросах окно уже не откроется |
| При извлечении ссылок с Wildberries открывается окно браузера | Это нормально: API Wildberries закрыт, поэтому ссылки собираются со страницы. Подождите 1–2 минуты, окно закроется само |
| `command not found: python` | Используйте `python3`, либо см. настройку алиаса в [`docs/getting-started.md`](docs/getting-started.md) |

## Для разработчиков: REST API

Если нужно подключить сбор данных к своей программе напрямую — доступен REST API. Интерактивная документация — на `http://localhost:8004/docs`.

Все пути API начинаются с `/v1`. Старые пути без версии (`/parse`, `/parse/batch` и т. д.) пока работают, но устарели — в новых интеграциях используйте `/v1`.

Все запросы, кроме `/v1/health`, `/v1/marketplaces` и `/v1/parse/detect`, требуют заголовок `X-API-Key`. Ключ создаётся в веб-панели: **Настройки → API-ключи → Создать ключ**. Он показывается один раз — сразу скопируйте его.

Поле `security.api_key` в `data/settings.yml` оставьте пустым — оно нужно только при переходе со старых версий: непустой ключ один раз переносится в список ключей. Если в списке есть ключ, помеченный «Небезопасный» (`4353456dfvbdfg34` из старого примера настроек), он всем известен — отзовите его.

### Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/` | Информация о сервисе |
| `GET` | `/v1/health` | Статус и uptime |
| `GET` | `/v1/marketplaces` | Список маркетплейсов |
| `GET` | `/v1/parse/detect?url=...` | Определить маркетплейс по URL |
| `POST` | `/v1/parse` | Парсинг одного товара |
| `POST` | `/v1/parse/batch` | Пакетный парсинг до 100 ссылок, ответ после обработки всех |
| `POST` | `/v1/jobs` | Фоновая задача на парсинг до 1000 ссылок |
| `GET` | `/v1/jobs` | Последние задачи этого ключа |
| `GET` | `/v1/jobs/{id}` | Статус, прогресс и результаты задачи |
| `POST` | `/v1/monitors` | Начать отслеживать цену товара |
| `GET` | `/v1/monitors` | Мои мониторы с последней ценой |
| `GET` / `PATCH` / `DELETE` | `/v1/monitors/{id}` | Монитор: посмотреть, поставить на паузу или сменить интервал, удалить |
| `GET` | `/v1/monitors/{id}/history` | История цен |
| `GET` | `/v1/alerts?since=...` | Изменения цен по моим мониторам |

### POST /v1/parse

```bash
curl -X POST http://localhost:8004/v1/parse \
  -H "X-API-Key: ваш-ключ" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.wildberries.ru/catalog/17386348/detail.aspx"}'
```

Ответ:

```json
{
  "success": true,
  "marketplace": "wildberries",
  "processing_time": 1.23,
  "data": {
    "title": "Название товара",
    "sku": "17386348",
    "original_price": 1500.0,
    "current_price": 1200.0,
    "images": ["https://..."],
    "source_url": "https://..."
  }
}
```

### POST /v1/parse/batch

```bash
curl -X POST http://localhost:8004/v1/parse/batch \
  -H "X-API-Key: ваш-ключ" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://www.wildberries.ru/catalog/17386348/detail.aspx",
      "https://ozon.ru/product/example-123456"
    ],
    "concurrency": 2
  }'
```

- `urls` — список ссылок (до 100)
- `concurrency` — количество параллельных запросов (по умолчанию `batch.concurrency` = 10, не больше `batch.max_concurrency` = 50)

Ответ приходит, только когда обработаны все ссылки. Для больших списков используйте задачи.

### Задачи: POST /v1/jobs

Задача принимает до 1000 ссылок, сразу отвечает `202` с `id` и парсит ссылки в фоне. Прогресс и готовые результаты — в `GET /v1/jobs/{id}`; опрашивайте его, пока `status` не станет `completed` или `failed`.

```bash
curl -X POST http://localhost:8004/v1/jobs \
  -H "X-API-Key: ваш-ключ" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://www.wildberries.ru/catalog/17386348/detail.aspx"]}'

curl http://localhost:8004/v1/jobs/<id> -H "X-API-Key: ваш-ключ"
```

- `status`: `pending` → `running` → `completed` (или `failed`, если задача прервалась целиком, например при перезапуске сервера — её стоит создать заново)
- `done` / `total` — прогресс; `results` — результаты готовых ссылок в порядке запроса, по формату как в `/v1/parse/batch`
- Задача видна только ключу, которым создана. Одновременно у ключа может быть до 5 незавершённых задач, иначе — `429`

### Мониторинг цен: /v1/monitors

Монитор периодически перепроверяет товар и записывает цену. Первая проверка — сразу после создания.

```bash
curl -X POST http://localhost:8004/v1/monitors \
  -H "X-API-Key: ваш-ключ" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.wildberries.ru/catalog/17386348/detail.aspx", "interval_seconds": 3600, "name": "Матрас"}'
```

- `interval_seconds` — как часто проверять; без него — значение сервера по умолчанию (`monitoring.default_interval_seconds`), не меньше `monitoring.min_interval_seconds`
- `GET /v1/monitors` — все мониторы ключа с последней ценой (`current_price`, `price_updated_at`) и статусом проверки (`last_status`)
- `PATCH /v1/monitors/{id}` — изменить только переданные поля: `{"active": false}` — пауза, `{"interval_seconds": null}` — вернуть интервал по умолчанию
- `DELETE /v1/monitors/{id}` — удалить монитор вместе с историей цен
- `GET /v1/monitors/{id}/history` — точки цены от старых к новым
- `GET /v1/alerts?since=2026-10-06T10:00:00Z` — изменения цены сильнее порогов сервера (`monitoring.drop_percent` / `rise_percent`), новые сверху. Передавайте в `since` время прошлого запроса, чтобы получать только новые

Мониторы видны только своему ключу и не попадают в веб-панель. Одну ссылку нельзя добавить одним ключом дважды (`409`), лимит — 500 мониторов на ключ. Если ключ отозвать, его мониторы останавливаются.

### Пример на Python

```python
import requests

API_URL = "http://localhost:8004"

response = requests.post(
    f"{API_URL}/v1/parse",
    headers={"X-API-Key": "ваш-ключ"},
    json={"url": "https://www.wildberries.ru/catalog/17386348/detail.aspx"},
)

data = response.json()
if data["success"]:
    product = data["data"]
    print(product["title"], product["current_price"])
```
