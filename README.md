# Grex Parser

Grex Parser сам собирает данные о товарах с крупнейших российских маркетплейсов: название, артикул, цены и фотографии. Достаточно вставить ссылку на товар — программировать для этого не нужно, всё делается через веб-панель в браузере.

## Поддерживаемые маркетплейсы

| Маркетплейс | Домены |
|---|---|
| Wildberries | `wildberries.ru`, `.by`, `.kz` |
| Ozon | `ozon.ru`, `.by`, `.kz` |
| Яндекс Маркет | `market.yandex.ru`, `.by` |
| MegaMarket | `megamarket.ru` |

---

## Что умеет

- **Собирает карточки товаров** — название, артикул, цену (обычную и со скидкой), фотографии, описание и характеристики.
- **Следит за ценами** — периодически перепроверяет сохранённые товары и строит график изменения цены во времени.
- **Присылает уведомления** — при заметном изменении цены и по расписанию отправляет Excel-отчёт в Telegram.
- **Извлекает ссылки списком** — по ссылке на каталог или страницу продавца находит все ссылки на товары внутри.
- **Работает с большими списками** — можно загрузить файл со ссылками и обработать их все разом.
- **Отдаёт данные по API** — для тех, кто хочет подключить сбор товаров к своей программе или сайту.

## Быстрый старт

Понадобится компьютер с macOS или Linux (на Windows — через WSL или Git Bash) и установленный **Python 3.12+**. Если Python ещё не установлен, см. подробную инструкцию в [`docs/getting-started.md`](docs/getting-started.md).

1. Откройте терминал в папке проекта.
2. Запустите скрипт установки и старта:

   ```bash
   ./start.sh
   ```

   Скрипт сам создаст нужное окружение, установит все зависимости и браузер для парсинга Ozon/MegaMarket — вмешиваться не нужно, только дождаться окончания.

3. Когда в терминале появится строка `API: http://localhost:8004`, сервис готов к работе.
4. Откройте в браузере **http://localhost:8004/admin** — это и есть панель управления.

   Логин и пароль по умолчанию: **admin / admin**. Сразу после первого входа смените их в разделе «Настройки → Пользователи» — так безопаснее.

Остановить сервис — нажать `Ctrl+C` в том же терминале. Запустить снова — повторить `./start.sh`.

## Как пользоваться веб-панелью

Всё управление происходит в браузере на странице `http://localhost:8004/admin`. Разделы в левом меню:

| Раздел | Для чего |
|---|---|
| **Главная** | Общая статистика: сколько товаров собрано, сколько задач выполнено. |
| **Цели** | Добавить ссылку на товар (одну или списком из файла) и запустить сбор данных. |
| **Извлечение ссылок** | Вставить ссылку на каталог или магазин продавца — получить список ссылок на все товары внутри. |
| **Товары** | Все собранные карточки товаров: поиск, фильтр по маркетплейсу, экспорт в файл. |
| **Мониторинг** | Включить слежение за ценой товара и посмотреть график её изменения. |
| **История задач** | Журнал всех запусков сбора данных — что удалось, что нет и почему. |
| **Настройки → Параметры мониторинга** | Подключить Telegram-бота для уведомлений о падении цены и регулярных отчётов. |
| **Настройки → Прокси** | Список прокси-серверов, если маркетплейсы блокируют прямые запросы. |
| **Настройки → Пользователи** | Управление логинами и паролями для входа в панель. |

Типичный сценарий: зайдите в **«Цели»**, вставьте ссылку на товар, нажмите «Запустить» — результат появится в разделе **«Товары»**. Чтобы следить за ценой этого товара со временем, включите его в разделе **«Мониторинг»**.

## Настройка

Все параметры сервиса хранятся в файле `data/settings.yml` — обычному пользователю туда заходить не обязательно, значения по умолчанию уже работают. Файл пригодится, если нужно:

- сменить порт или адрес, на котором работает сервис (`app.host`, `app.port`);
- подключить прокси — добавить их в `data/proxy.txt` построчно в формате `login:password@host:port` и включить `proxy.active: true`;
- настроить Redis (`redis.host`, `redis.port`) — он не обязателен, но без него не сохраняется статистика в дашборде между перезапусками.

Полное описание всех настроек — в [`docs/getting-started.md`](docs/getting-started.md).

## Возможные проблемы

| Проблема | Решение |
|---|---|
| Redis недоступен | Сервис всё равно запустится, но статистика в дашборде работать не будет |
| Не находит браузер для Ozon/MegaMarket | Выполните `.venv/bin/patchright install chromium` |
| При первом парсинге Ozon/MegaMarket/Яндекс Маркета открывается окно браузера | Это нормально — так собираются куки; при следующих запросах окно уже не откроется |
| `command not found: python` | Используйте `python3`, либо см. настройку алиаса в [`docs/getting-started.md`](docs/getting-started.md) |

## Для разработчиков: REST API

Если нужно подключить сбор данных к своей программе напрямую — доступен REST API. Интерактивная документация — на `http://localhost:8004/docs`.

### Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/` | Информация о сервисе |
| `GET` | `/health` | Статус и uptime |
| `GET` | `/marketplaces` | Список маркетплейсов и примеры URL |
| `GET` | `/parse/detect?url=...` | Определить маркетплейс по URL |
| `POST` | `/parse` | Парсинг одного товара |
| `POST` | `/parse/batch` | Пакетный парсинг |

### POST /parse

```bash
curl -X POST http://localhost:8004/parse \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.wildberries.ru/catalog/17386348/detail.aspx"}'
```

Ответ:

```json
{
  "success": true,
  "marketplace": "wildberries",
  "processing_time": 1.23,
  "data": {
    "title": "Название товара",
    "sku": "17386348",
    "original_price": 1500.0,
    "current_price": 1200.0,
    "images": ["https://..."],
    "source_url": "https://..."
  }
}
```

### POST /parse/batch

```bash
curl -X POST http://localhost:8004/parse/batch \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://www.wildberries.ru/catalog/17386348/detail.aspx",
      "https://ozon.ru/product/example-123456"
    ],
    "concurrency": 2
  }'
```

- `urls` — список ссылок (до 100)
- `concurrency` — количество параллельных запросов

### Пример на Python

```python
import requests

API_URL = "http://localhost:8004"

response = requests.post(
    f"{API_URL}/parse",
    json={"url": "https://www.wildberries.ru/catalog/17386348/detail.aspx"},
)

data = response.json()
if data["success"]:
    product = data["data"]
    print(product["title"], product["current_price"])
```
