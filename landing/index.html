Возможности

Всё что нужно для работы с данными

Парсер берёт на себя обход защиты, управление куки и прокси — вам остаётся только работать с результатом.

🔗

Один URL — полная карточка

Передайте ссылку на товар и получите название, артикул, цены, изображения, описание и характеристики в одном ответе.

⚡

Пакетный парсинг

Парсер поддерживает массовую выгрузку товаров из категорий, страниц продавцов и результатов фильтрации.

🛡️

Обход защиты

Встроенная ротация User-Agent, имплементация реального браузера Chrome и автоматическое управление куки-сессиями, позволяет защитить парсер от блокировок.

🔄

Прокси из коробки

Подключите список прокси — парсер автоматически чередует их между запросами. Поддержка HTTP и SOCKS5.

📦

Извлечение ссылок

Передайте URL категории или каталога — парсер обойдёт все страницы и вернёт список ссылок на товары.

🖥️

Админ-панель

Встроенный веб-интерфейс для управления заданиями, просмотра результатов и экспорта данных в CSV, XLSX или JSON.

Админ-панель

Удобный веб-интерфейс

Управляйте парсером через браузер — без командной строки. Запускайте задания, смотрите результаты и экспортируйте данные.

🎯

Targets — управление целями

Добавляйте ссылки на товары. Маркетплейс определяется автоматически по URL. Каждой цели можно задать имя для удобства навигации.

  • Добавление по одной ссылке или файлом
  • Авто-определение маркетплейса
  • Включение и отключение целей без удаления
  • Ручной запуск парсинга в один клик
🛍️

Products — результаты парсинга

Все собранные товары в одной таблице. Фильтрация по маркетплейсу, поиск по названию, просмотр описания и характеристик в модальном окне.

  • Название, артикул, цены, изображение
  • Описание и характеристики товара
  • Фильтрация по маркетплейсу
  • Экспорт в CSV, XLSX или JSON
📋

Jobs — история заданий

Полный журнал всех запросов на парсинг. Отслеживайте статус, время обработки и ошибки по каждому товару.

  • Статус: Success / Error
  • Время обработки каждого запроса
  • Дата и время запуска
  • Фильтрация по маркетплейсу и статусу
🛡️

Proxies — управление прокси

Подключите прокси и настройте их использование отдельно для каждого маркетплейса. Поддержка HTTP и SOCKS5.

  • Добавление прокси через удобную форму
  • Включение/отключение по маркетплейсу
  • Поддержка HTTP и SOCKS5
  • Ротация прокси между запросами
