# C4, уровень 1: контекст системы

Кто пользуется Grex Parser и с какими внешними системами он работает.

```mermaid
flowchart TB
    owner(["Владелец установки<br/>работает в веб-панели /admin"])
    integrator(["Внешняя программа<br/>REST API /v1, ключ X-API-Key"])

    grex["Grex Parser<br/>собирает карточки товаров, следит за ценами,<br/>шлёт отчёты"]

    marketplaces[["9 маркетплейсов<br/>Wildberries, Ozon, Яндекс Маркет, MegaMarket,<br/>ММ, Ситилинк, ВсеИнструменты, CDEK.Shopping, Бигам"]]
    proxies[["Прокси-серверы<br/>российские IP для части площадок"]]
    telegram[["Telegram Bot API<br/>отправка Excel-отчётов"]]

    owner -- "цели, товары, мониторинг, настройки" --> grex
    integrator -- "парсинг, задачи, мониторы цен" --> grex
    grex -- "HTTP-запросы и браузер Chromium" --> proxies
    proxies --> marketplaces
    grex -- "напрямую, если прокси выключены" --> marketplaces
    grex -- "sendDocument по расписанию получателя" --> telegram
```

## Границы

- **Внутри системы:** всё, что запускается из этого репозитория: сервер FastAPI, фоновые задачи, база SQLite, браузеры для парсинга.
- **Снаружи:** маркетплейсы (их API и страницы меняются без предупреждения), прокси (их выдаёт владелец установки), Telegram, клиенты API.
- **Redis** на этом уровне считается частью установки, а не внешней системой: он необязателен и ставится рядом (см. [контейнеры](c4-container.md)).
