# 0008. Отказ от лицензирования, открытый исходный код

- **Статус:** Принято
- **Дата:** 2026-10-14 (решение принято раньше, записано задним числом)
- **Задача:** #13

## Контекст

Раньше проект распространялся закрыто:
- лицензия проверялась через внешний сервис (`services/license.py`, JWT-токены, кэш на диске);
- от лицензии зависел доступ к отдельным маркетплейсам;
- сборки обфусцировались через PyArmor (цели в `Makefile`).

В сентябре 2026 всё это удалено (коммиты ветки `issues-13`: «remove license service layer», «remove pyarmor build/release targets», «drop API key prompt and license check from start.sh» и другие), а репозиторий стал публичным.

## Решение

Проект бесплатный, исходный код открыт, проверки лицензии и обфускации нет.

❓ Причины перехода и рассмотренные альтернативы в репозитории не записаны. Их нужно дописать со слов автора.

## Альтернативы

❓ Не записаны.

## Последствия

- Любой может запустить проект без ключа активации.
- В репозитории пока нет файла `LICENSE`, поэтому юридически код не открыт: это задача #33, лицензию выбирает автор.
- Всё, что попадает в репозиторий, публично: секреты и примеры значений проверяются при каждом изменении (см. ADR 0002, ADR 0005).
