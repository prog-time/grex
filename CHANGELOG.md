## [v1.0.2] — 2026-10-13

### Bug Fixes

- Свежий клон снова запускается через `./start.sh`. Раньше сервис падал с `FileNotFoundError: data/settings.yml`: файла настроек нет в репозитории, а скрипт только предупреждал об этом. Теперь `start.sh` при первом запуске сам создаёт `data/settings.yml` из `data/settings.yml.example`. Уже существующий файл скрипт не трогает.
- API и логи показывают правильную версию приложения. В v1.0.1 там по ошибке оставалась `1.0.0`.

## [v1.0.1] — 2026-10-13

### Bug Fixes

- Новая установка больше не получает рабочий API-ключ, который знают все. В `data/settings.yml.example` поле `security.api_key` теперь пустое, а первый ключ создаётся в панели: «Настройки → API-ключи». Если вы ставили Grex Parser раньше, загляните в этот раздел: ключ `4353456dfvbdfg34` из старого примера настроек помечен там как «Небезопасный», его нужно отозвать.
- `start.sh` на Windows больше не обрывается молча на шаге «Проверка Python». Скрипт пропускает заглушки Microsoft Store вместо Python, находит Python через загрузчик `py`, а если подходящего Python нет, пишет, как его поставить.

### Documentation

- README переписан простым языком, без изменений по сути.
- Инструкция по установке и правила проекта обновлены: ключи API создаются в панели, поле `security.api_key` нужно только при переходе со старых версий. Из инструкции убрана устаревшая фраза о том, что `start.sh` спрашивает API-ключ.

## [v1.0.0] — 2026-10-13

Первый открытый релиз Grex Parser: сбор карточек товаров с российских маркетплейсов, мониторинг цен и уведомления через веб-панель и REST API.

### Features

- Парсинг карточек товаров с 9 площадок: Wildberries, Ozon, Яндекс Маркет, MegaMarket, ММ (бывший KazanExpress), Ситилинк, ВсеИнструменты.ру, CDEK.Shopping и Бигам — название, артикул, цены, фотографии, описание и характеристики
- Веб-панель `/admin` на русском языке: цели парсинга, товары, история задач, пакетные действия, экспорт в CSV, XLSX и JSON
- Извлечение ссылок на все товары из каталога, бренда или магазина продавца
- Мониторинг цен: перепроверка по расписанию, история и график цены, оповещения об изменении цены выше порога, очистка мониторинга целиком
- Отчёты по мониторингу в Excel и уведомления в Telegram по расписанию; токен бота хранится в зашифрованном виде
- REST API с версией `/v1`: парсинг одного товара и пакетный парсинг, фоновые задачи до 1000 ссылок, мониторы цен и оповещения для каждого API-ключа
- API-ключи в базе данных: создание и отзыв в панели, хранится только хеш ключа
- Прокси с HTTP и SOCKS5, загрузка списка из файла
- Скачивание фотографий товаров в фоне через очередь Redis
- Раздел «Поблагодарить автора» в панели

### Bug Fixes

- Извлечение ссылок продавца Wildberries переходит на браузер, когда API Wildberries отвечает 403
- Устойчивость парсера Wildberries к смене CDN-хостов и API v4
- Корректное время (UTC) и контраст бейджей в панели мониторинга

### Maintenance

- Удалена система лицензирования: проект распространяется как открытый исходный код
- Старые пути API без `/v1` работают, но помечены устаревшими
- CI: ruff, pytest и проверка запуска приложения; версии зависимостей зафиксированы в `requirements-ci.txt`, обновления предлагает Dependabot
- Пример настроек `data/settings.yml.example` и запуск одной командой `./start.sh`
